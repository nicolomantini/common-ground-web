Put counselor photos in this folder, e.g. `maya-ortiz.jpg`.

Then in js/counselors-data.js set that counselor's `photo` field to:
  "images/maya-ortiz.jpg"

Tips:
- Square photos work best (the site crops them into a circle).
- Keep files reasonably small (under ~300KB) so the page loads fast — export at
  roughly 400x400px, JPEG quality 80, before uploading.
